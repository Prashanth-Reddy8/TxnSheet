## TxnSheet 1.0.2 alpha 3

This update fixes Google Sheet setup failures reported as `SHEETS_HTTP_400`.

### What changed

- Creates the spreadsheet with Google's minimal supported request first.
- Adds and configures the Transactions, Dashboard, and Config sheets in a separate batch update.
- Shows clearer guidance for cancelled sign-in, network failures, missing permissions, and OAuth configuration errors.

### Install

Download the APK below and choose **Update** when Android asks. It uses the same signing certificate and a higher version code, so you do not need to uninstall the existing app.

This is a debug-signed prerelease for device testing.
